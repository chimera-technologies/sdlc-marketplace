# POC examples

Artifacts from the proof of concept, kept as worked examples of what each
stage produces. They are not used by the plugin.

- `intent/workout-plan-todo-poc.md`: an intent written from a requirement
  document (Jira Epic SCRUM-7), and `specs/workout-plan-todo-poc.md`: the spec
  generated from it by `sdlc:write-spec` (stack decision, five stories).
  The app itself was then built stage by stage in `bala-chimera/workout-plan-poc`.
- `intent/p95-latency-claims-api.md`: an intent drafted headless from a Maintain
  latency breach.
- `.sdlc/`: the owners and Jira settings the POC used.
